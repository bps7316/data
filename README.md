# Portal Data Kependudukan — BPS Kabupaten Enrekang

Halaman ini hanya pembungkus (iframe) yang memuat portal data kependudukan.
Alamat tujuan diatur di `index.html` (variabel `PORTAL_EXEC`).

Halaman yang tersedia:
- `?page=home` (default)
- `?page=portal`
- `?page=tentang`
- `?page=laporkan`
- `?page=bukutamu`
- `?page=layanan`
